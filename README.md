# 📈 AI Sales Forecasting System


Live Demo : https://ai-sales-forecast-system-2.onrender.com


## 🚀 Overview

The AI Sales Forecasting System is a Machine Learning-powered web application designed to analyze historical sales data, identify trends, and generate accurate sales forecasts. The system helps businesses make data-driven decisions by providing interactive dashboards, predictive analytics, and visual insights.

By leveraging machine learning algorithms and advanced data visualization techniques, the application enables organizations to forecast future sales, monitor product performance, and optimize inventory planning.

## 🎯 Objectives

* Analyze historical sales data
* Forecast future sales trends
* Identify top-performing products
* Visualize sales patterns using charts and dashboards

## ⚙ Installation

### Clone Repository

```bash
git clone <repository-url>
cd AI_Sales_Forecasting_System
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

Windows:

```bash
venv\Scripts\activate
```

Linux / Mac:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
streamlit run app.py
```
